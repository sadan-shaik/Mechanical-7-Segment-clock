Mechanical 7-Segment Display

A Servo-Driven Mechanical Digital Display

An embedded systems project focused on developing a mechanical seven-segment display using servo motors, Arduino Uno, PCA9685 and NVIDIA Jetson Nano.

Project Overview

This project explores the design and development of a mechanical digital display in which individual segments are physically actuated to represent numbers and selected characters.

Unlike conventional electronic seven-segment displays, this system uses mechanical movement to change the appearance of each segment.

Hardware Components

- Arduino Uno R3
- NVIDIA Jetson Nano
- PCA9685 16-Channel PWM Servo Driver
- SG90 Servo Motors
- External DC Power Supply
- Mechanical Segment Assemblies
- Connecting Wires and Mounting Structure

System Architecture

The project combines three major areas:

1. Mechanical System: Physical construction and movement of the seven-segment elements.
2. Embedded Control: Arduino-based servo control using the PCA9685 driver.
3. Computing System: NVIDIA Jetson Nano for Python-based computing and system integration.

Engineering Challenges

The development involves several engineering challenges:

- Designing movable mechanical segments.
- Achieving accurate segment positioning.
- Coordinating multiple servo motors.
- Managing power requirements.
- Developing reliable communication between computing and embedded controllers.
- Integrating mechanical and electronic components.
